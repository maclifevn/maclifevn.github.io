# MFinder 1.3

## English

- Introduces signed Sparkle updates with daily automatic checks and an explicit manual check command.
- Safely postpones installation while file operations, Folder Sync, remote uploads, Finder mailbox requests, or locked-folder sessions are active.
- Adds a visual search result preview with thumbnails, Quick Look, Open, and Reveal in Finder actions.
- Improves Folder Sync reliability, remote uploads, batch rename, duplicate detection, PDF tools, Folder Lock recovery, and Storage Analyzer responsiveness.
- Includes the latest stability, data-integrity, localization, and performance fixes.

## Tiếng Việt

- Bổ sung cập nhật Sparkle có chữ ký, tự kiểm tra hằng ngày và lệnh kiểm tra thủ công.
- Trì hoãn cài đặt an toàn khi thao tác file, Folder Sync, remote upload, request từ Finder hoặc phiên Folder Lock đang hoạt động.
- Bổ sung preview trực quan cho kết quả tìm kiếm với thumbnail, Quick Look, Open và Reveal in Finder.
- Tăng độ tin cậy của Folder Sync, remote upload, đổi tên hàng loạt, tìm file trùng, công cụ PDF, phục hồi Folder Lock và hiệu năng Storage Analyzer.
- Bao gồm các bản sửa mới nhất về độ ổn định, toàn vẹn dữ liệu, bản địa hóa và hiệu năng.
