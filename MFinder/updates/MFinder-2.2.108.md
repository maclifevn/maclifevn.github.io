# MFinder 2.2.108 (260)

## English

1. Settings: Add animated guides for Window Previews and Peek, Drop Tray, Menu Bar Icons, screenshots, Scrolling Capture, Screen OCR and screen-edge Notes. Guides follow your settings and respect Reduce Motion.
2. Dock Preview: Fix previews sometimes stopping after drag interactions and improve compatibility with mouse utilities. Add pointer-monitor details to exported diagnostics.
3. License management: Keep the verification dialog and entered code when switching between MFinder and Mail. Improve recovery when a device-verification session expires.
4. AI Search: Limit CPU use during background indexing and give search queries priority.
5. Image Preview: Fix the loading indicator sometimes returning after an image has finished loading.
6. Menu Bar Icons: On macOS 27, new icons start hidden. Fix choosing the wrong icon when hidden icons report stale positions.

## Tiếng Việt

1. Cài đặt: Thêm minh hoạ chuyển động cho Window Previews và Peek, Drop Tray, biểu tượng thanh menu, chụp màn hình, chụp cuộn, Screen OCR và ghi chú ở mép màn hình. Minh hoạ thay đổi theo cài đặt và tuân theo Giảm chuyển động.
2. Dock Preview: Sửa tình trạng ảnh xem trước có thể ngừng phản hồi sau thao tác kéo thả; cải thiện tương thích với tiện ích chuột. Bổ sung thông tin monitor con trỏ trong gói chẩn đoán.
3. Quản lý bản quyền: Giữ hộp thoại xác minh và mã đã nhập khi chuyển giữa MFinder và Mail. Cải thiện khôi phục khi phiên xác minh thiết bị hết hạn.
4. AI Search: Giới hạn CPU khi lập chỉ mục nền và ưu tiên xử lý truy vấn tìm kiếm.
5. Trình xem ảnh: Sửa lỗi vòng quay tải ảnh đôi khi hiện lại sau khi ảnh đã tải xong.
6. Biểu tượng thanh menu: Trên macOS 27, biểu tượng mới được ẩn sẵn. Sửa chọn nhầm biểu tượng khi biểu tượng ẩn báo vị trí cũ.
