# MFinder 2.2.154 (316)

## English

1. Fix App Keys getting stuck when turning it back on. App Keys always uses Right Command; Find Windows uses Right Option, with independent on/off switches.
2. App Keys is enabled by default for new configurations; saved on/off choices and assigned letters are preserved.

## Tiếng Việt

1. Sửa lỗi không bật lại được App Keys. Cố định Command phải cho App Keys và Option phải cho Tìm cửa sổ; hai tính năng bật/tắt độc lập.
2. App Keys mặc định bật cho cấu hình mới; giữ trạng thái bật/tắt đã lưu và các chữ đã gán.
