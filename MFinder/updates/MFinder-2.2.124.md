# MFinder 2.2.124 (279)

## English

1. AppSwitcher: Add an option to enable or disable AppSwitcher for quick Cmd-Tab presses.
2. AppSwitcher: Use Command + ` to switch between windows within the same app. Change the shortcut in Settings.
3. AppSwitcher: Show window thumbnails faster.
4. Recording: Fix minor bugs.
5. Text recognition: Improve first-use recognition speed.
6. Preview: Add an option to skip confirmation when moving RAW images to Trash; fix minor bugs.
7. Screenshot: Optionally use Command-Shift-3 and Command-Shift-4 to capture screenshots. Show pointer guides.

6. Preview: Thêm lựa chọn bỏ xác nhận chuyển ảnh RAW vào Thùng rác; sửa một số lỗi nhỏ
