# MFinder 2.2.133 (292)

## English

1. Image Tools: Add separate Crop, Annotate and Redact tools while preserving edits and Undo when switching tools.
2. Optimize: Add ID-photo presets, crop guides and custom photo dimensions.
3. Image Tools: Fix missing image thumbnails and make the Save to control more compact.
4. Image editing: Show tooltips with tool names and keyboard shortcuts.
5. Annotate: Fix Highlight regions not appearing while drawing or after releasing the mouse.

5. Annotate: Sửa lỗi vùng Highlight không hiện trong lúc vẽ hoặc sau khi thả chuột.
6. Thao tác nhanh: Thêm Keyboard Clean để tạm khóa bàn phím khi vệ sinh.
