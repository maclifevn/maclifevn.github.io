# MFinder 1.7.3

## English

- Redesigns Notes with smoother animations.
- Improves reliability when validating paste operations in Finder and extracting archive previews.
- Adds an Extract button when previewing RAR archives.
- Improves reliability when using Command-X to cut files and folders.
- Disables Folder Lock for folders synced through iCloud or another File Provider.

## Tiếng Việt

- Thiết kế lại Notes với animation mượt hơn
- Tăng độ tin cậy khi xác thực thao tác dán trong Finder và trích xuất preview tệp nén.
- Thêm nút Extract khi Preview file rar
- Tăng độ tin cậy khi bật tính năng Cắt Files/Folders bằng Cmd + X
- Tắt tính năng Lock Folder trên các thư mục có đồng bộ với Cloud
