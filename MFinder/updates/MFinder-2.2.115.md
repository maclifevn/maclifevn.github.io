# MFinder 2.2.115 (268)

## English

1. Drop Tray: Retry a failed startup when dragging files again so a temporary storage error does not leave the tray unable to receive files.
2. Drop Tray: Keep warnings visible after a rejected drop so you can read the error details and retry. Show the blue drop border only when the tray can receive files.
3. Drop Tray: Clean up unused tray records from earlier sessions and record startup failure codes for troubleshooting.

## Tiếng Việt

1. Drop Tray: Tự thử lại khi kéo file sau lần khởi tạo lỗi, tránh để khay không thể nhận file vì lỗi lưu trữ tạm thời.
2. Drop Tray: Giữ cảnh báo hiển thị sau lần thả không thành công để bạn xem chi tiết lỗi và thử lại. Chỉ hiện viền xanh khi khay có thể nhận file.
3. Drop Tray: Dọn bản ghi khay trống không dùng từ phiên trước và ghi mã lỗi khởi tạo để hỗ trợ chẩn đoán.
