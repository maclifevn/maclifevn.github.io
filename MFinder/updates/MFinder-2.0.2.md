# MFinder 2.0.2

## English

- Fixes App Switcher dropping open windows: windows an application was slow to report no longer disappear from Command-Tab.
- Command-Tab now returns to the window you came from, whatever application it belongs to. Previously an app with several windows made you step through all of them first.
- Indexing uses far less memory on large photo libraries, and images with no readable text are no longer re-scanned with OCR at every launch.
- Settings now reports the number of files that are actually searchable.

## Tiếng Việt

- Sửa lỗi App Switcher làm mất cửa sổ đang mở: cửa sổ của ứng dụng phản hồi chậm không còn biến mất khỏi Command-Tab.
- Command-Tab giờ quay lại đúng cửa sổ bạn vừa rời, bất kể nó thuộc ứng dụng nào. Trước đây ứng dụng có nhiều cửa sổ buộc bạn phải đi hết chúng trước.
- Lập chỉ mục tốn ít bộ nhớ hơn hẳn với thư viện ảnh lớn, và ảnh không có chữ đọc được sẽ không bị OCR lại mỗi lần khởi động.
- Cài đặt hiển thị đúng số tệp thực sự tìm kiếm được.
