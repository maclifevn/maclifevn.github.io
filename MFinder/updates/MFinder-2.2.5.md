# MFinder 2.2.5

## English

- Added the **Shift+B** shortcut to switch the image preview background between default, white, black, and checkerboard.
- Fixed pasting image files from Finder into a Note sometimes showing the file icon instead of the image.

## Tiếng Việt

- Thêm phím tắt **Shift+B** để chuyển nền xem ảnh giữa mặc định, trắng, đen và ô caro.
- Sửa lỗi dán file ảnh từ Finder vào Note đôi khi hiện biểu tượng file thay vì nội dung ảnh
