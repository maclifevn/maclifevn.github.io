# MFinder 2.2.114 (267)

## English

1. PDF Edit: Rotate images from just outside any corner. Keep handles aligned with the rotated image and preserve aspect ratio when resizing.
2. PDF Edit: Click outside an image to deselect it without moving it. Image inserts and adjustments take effect in the working copy when each action finishes.
3. PDF Edit: Undo and redo image insertion, movement, resizing and rotation with the toolbar or ⌘Z and ⇧⌘Z.
4. PDF Edit: Paste copied image files as image content instead of Finder file icons.
5. PDF Tools: Fix Close → Discard Changes leaving the editor open. Keep Cancel and Save Copy behavior consistent.
6. PDF Edit: Keep text guides behind inserted images so opaque image areas match the exported PDF. Preserve genuine image transparency and selection handles.

## Tiếng Việt

1. PDF Edit: Xoay ảnh bằng cách kéo ngay ngoài bốn góc. Khung chọn bám theo góc xoay và giữ tỉ lệ ảnh khi đổi kích thước.
2. PDF Edit: Click ra ngoài để bỏ chọn mà không làm ảnh nhảy vị trí. Thao tác chèn và chỉnh ảnh được ghi vào bản làm việc khi kết thúc mỗi thao tác.
3. PDF Edit: Hoàn tác và làm lại từng lần chèn, di chuyển, đổi kích thước và xoay ảnh bằng thanh công cụ hoặc ⌘Z và ⇧⌘Z.
4. PDF Edit: Dán nội dung file ảnh đã sao chép thay vì biểu tượng file của Finder.
5. PDF Tools: Sửa lỗi Close → Discard Changes không đóng trình chỉnh sửa. Giữ hành vi Cancel và Save Copy nhất quán.
6. PDF Edit: Đặt khung chữ phía sau ảnh chèn để vùng ảnh đục hiển thị giống file PDF xuất. Giữ nguyên vùng trong suốt thật và tay nắm chọn ảnh.
