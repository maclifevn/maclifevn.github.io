# MFinder 1.5.1

## English

- Merge PDFs: drag more PDFs or whole folders onto the file list to add them, reorder files by dragging (or the right-click menu), and remove any file — so you can assemble the exact merge you want without reopening the tool.

## Tiếng Việt

- Gộp PDF: kéo thêm PDF hoặc cả thư mục vào danh sách để bổ sung, kéo để sắp xếp lại thứ tự (hoặc dùng menu chuột phải), và xoá bất kỳ file nào — sắp xếp đúng bản gộp bạn muốn mà không cần mở lại công cụ.
