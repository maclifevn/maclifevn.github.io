# MFinder 2.2.153 (314)

## English

1. Folder Icon: Customize folder icons with 84 popular presets.
2. App Keys: Hold Right Command and press the first letter of an app’s name to open it; repeat the letter to cycle through apps with the same initial.
3. Find Windows: Hold Right Option to see open windows numbered 1–9; press a number to switch immediately or use Command-F to search titles.
4. App Switcher: Command-Tab now numbers window previews, supports title search with Command-F and closes the selected window with Command-W.
5. Clipboard History: Search an encrypted local history of copied text, images and files, with sensitive-content filtering and keyboard paste controls.
6. Mouse: Assign mouse gestures with 96 verified mouse profiles; mice outside the library can still be recognized and assigned gestures. More updates are planned.
7. Screen Capture: Add rounded corners and shadows, pin captures above other windows, and improve toolbar layout and text editing focus.
8. Snap Areas: Animate window placement when using keyboard shortcuts.
9. Image Tools: Fix HEIC conversion defaults and add a 2048 px / 500 KB Website WebP preset.
10. Recording: Preserve precise edit boundaries and verify audio tails before encoding accelerated exports.

## Tiếng Việt

1. Biểu tượng thư mục: Thêm chức năng đổi icon thư mục, có sẵn 84 mẫu phổ biến.
2. Phím chuyển ứng dụng: Giữ Command (bên phải) rồi bấm chữ cái đầu của ứng dụng để mở đúng ứng dụng đó; nếu trùng chữ thì bấm nhiều lần để xoay vòng.
3. Tìm cửa sổ: Giữ Option phải để xem các cửa sổ đang mở, đánh số 1–9; bấm số để chuyển ngay hoặc dùng Command-F để tìm tiêu đề.
4. Chuyển ứng dụng: Cmd-Tab giờ thêm số cho các cửa sổ, hỗ trợ tìm cửa sổ bằng Command-F và đóng đúng cửa sổ đang chọn bằng Command-W.
5. Lịch sử clipboard: Tìm văn bản, ảnh và tệp đã sao chép trong lịch sử mã hóa lưu trên máy, có lọc nội dung nhạy cảm và điều khiển dán bằng bàn phím.
6. Chuột: Thêm gán cử chỉ chuột, có 96 profile chuột đã xác minh; các chuột khác vẫn nhận diện và gán cử chỉ được. Tính năng này sẽ được cập nhật thêm.
7. Chụp màn hình: Thêm bo góc và đổ bóng, ghim ảnh nổi trên các cửa sổ khác, cải thiện bố cục thanh công cụ và focus khi sửa chữ.
8. Vùng chia cửa sổ: Thêm chuyển động khi dùng phím tắt.
9. Công cụ ảnh: Sửa mặc định chuyển HEIC, thêm mẫu WebP cho website 2048 px / 500 KB.
10. Ghi hình: Giữ chính xác ranh giới chỉnh sửa và kiểm tra phần đuôi âm thanh trước khi mã hóa bản xuất tăng tốc.
