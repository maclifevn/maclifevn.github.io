# MFinder 2.2.107 (254)

## English

1. License management: Remove an old Mac from the Mac you are using after email verification, with confirmation before removal. The current Mac stays activated.
2. Drop Tray: Fix file exports to File Provider folders, including Dropbox. Add private, optional drag diagnostics for troubleshooting.

## Tiếng Việt

1. Quản lý bản quyền: Gỡ Mac cũ ngay từ Mac đang dùng sau khi xác minh email, có xác nhận trước khi gỡ. Mac hiện tại vẫn được kích hoạt.
2. Drop Tray: Sửa xuất tệp vào thư mục File Provider, bao gồm Dropbox. Thêm chẩn đoán kéo thả tùy chọn, bảo vệ thông tin riêng tư.
