# MFinder 2.2.117 (271)

## English

1. PDF Redact: Remove hidden text properties associated with redacted content, including properties referenced indirectly by PDF resources.
2. PDF Edit: Keep image movement and resizing aligned when a rotated page changes layout. Protect unsaved edits when switching tools, closing, quitting or updating MFinder.
3. Image Tools: Protect unsaved batch edits during Quit and Update. Preserve recovery records for files already exported when a later operation fails or is cancelled.
4. Archives: Keep recovery records tied to files created by the current extraction. Prevent Undo from removing pre-existing contents when extracting into an existing folder.
5. Quick Share: Prevent late responses from restoring a revoked link or overwriting state after an account change.
6. Drop Tray: Recover notch drop readiness after a tray fails to load or closes. Preview: Retry failed file opens while preserving the original request and access permissions.
7. Menu Bar Organizer: Move Accessibility reads off the main thread and ignore stale results after cancellation, permission or display changes.

## Tiếng Việt

1. PDF Redact: Loại bỏ thuộc tính văn bản ẩn gắn với nội dung bị che xoá, kể cả thuộc tính được tham chiếu gián tiếp qua tài nguyên PDF.
2. PDF Edit: Giữ thao tác di chuyển và đổi kích thước ảnh đúng vị trí khi trang xoay thay đổi bố cục. Bảo vệ chỉnh sửa chưa lưu khi đổi công cụ, đóng cửa sổ, thoát hoặc cập nhật MFinder.
3. Image Tools: Bảo vệ chỉnh sửa hàng loạt chưa lưu khi thoát hoặc cập nhật. Giữ bản ghi khôi phục cho file đã xuất nếu thao tác tiếp theo lỗi hoặc bị huỷ.
4. Archives: Gắn bản ghi khôi phục với đúng file do lượt giải nén tạo ra. Ngăn Undo xoá nội dung có sẵn khi giải nén vào thư mục đang tồn tại.
5. Quick Share: Ngăn phản hồi đến muộn khôi phục liên kết đã thu hồi hoặc ghi đè trạng thái sau khi đổi tài khoản.
6. Drop Tray: Khôi phục khả năng nhận file qua notch sau khi khay tải lỗi hoặc đóng. Preview: Cho thử lại lần mở file lỗi, giữ yêu cầu ban đầu và quyền truy cập.
7. Menu Bar Organizer: Đọc thông tin Accessibility ngoài luồng giao diện và bỏ kết quả cũ sau khi huỷ, đổi quyền hoặc đổi màn hình.
