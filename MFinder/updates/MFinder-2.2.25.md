# MFinder 2.2.25

## English

1. Smaller installation: reduced the app’s installed size by removing unnecessary symbol metadata. All features and support for Apple silicon and Intel are preserved.

2. Drop Tray: improved memory cleanup when cancelling a quit or update wait, including status checks that have not finished.

## Tiếng Việt

1. Giảm dung lượng cài đặt: loại bỏ metadata symbol không cần thiết trong bản phát hành. Giữ nguyên toàn bộ tính năng và hỗ trợ Apple silicon, Intel.
2. Drop Tray: dọn dẹp bộ nhớ tốt hơn khi hủy cửa sổ chờ thoát hoặc cập nhật, kể cả khi lượt kiểm tra trạng thái chưa hoàn tất.
