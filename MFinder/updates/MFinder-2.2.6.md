# MFinder 2.2.6

## English

1. **Redesigned Settings:** organized features into clear groups and combined related pages into tabs.
2. **Added image preview backgrounds:** switch between default, white, black, and checkerboard with **Shift+B** or the **View** menu.
3. **Improved detail when zooming into large JPEG images.**
4. **Improved RAW image quality in Fit mode**, showing a preview sooner while finer details load.
5. **Fixed** thumbnails in Filmstrip mode.
6. **Fixed pasting images from Finder into Notes** sometimes showing only the file icon instead of the image.

## Tiếng Việt

1. **Thiết kế lại Settings:** sắp xếp các tính năng theo nhóm rõ ràng, gom các trang liên quan thành tab.
2. **Thêm lựa chọn nền xem ảnh:** chuyển giữa mặc định, trắng, đen và ô caro bằng **Shift+B** hoặc menu **View**.
3. **Cải thiện độ chi tiết khi phóng to ảnh JPEG kích thước lớn.**
4. **Cải thiện chất lượng ảnh RAW ở chế độ vừa khung**, hiển thị ảnh xem trước sớm hơn trong lúc tải chi tiết.
5. **Sửa lỗi** thumbnail ở chế độ Filmstrip
6. **Sửa lỗi dán ảnh từ Finder vào Notes** đôi khi chỉ hiện biểu tượng file thay vì nội dung ảnh
